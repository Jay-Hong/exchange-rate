# 📚 문서 업데이트 체크리스트

CLAUDE.md의 "문서 관리 가이드라인" 섹션을 자동 실행합니다.

## 실행 순서

### 1. CLAUDE.md 읽기
- "## 문서 관리 가이드라인" 섹션 확인
- 각 문서별 업데이트 기준 파악

### 2. 변경된 파일 분석
```bash
git diff --cached --name-only  # staged 파일
git diff --name-only HEAD      # working directory 변경 파일
```

### 3. 자동 체크 실행

**✅ CRAWLERS.md 업데이트 필요?**
- 크롤러 로직 변경, 특수 로직 추가, 트러블슈팅 패턴 발견 등

**✅ DECISIONS.md 업데이트 필요? (ADR 4가지 기준)**
- 비가역성 + 영향 범위 + 대안 존재 + 장기 유지

**✅ CLAUDE.md 업데이트 필요?**
- 은행 개수, 통화, DB 스키마, 아키텍처 변경 등

### 4. 결과 제시
- 업데이트 필요 문서 목록 정리
- 각 문서별 변경 이유 요약
- 사용자에게 진행 여부 확인

### 5. 자동 업데이트 (사용자 승인 시)
- 해당 문서 읽기 → 수정 → 변경사항 요약 제시
